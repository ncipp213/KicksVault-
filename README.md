# 👟 KicksVault — Modern Shoe Store & Catalog Website

![KicksVault Banner](https://via.placeholder.com/1200x400/111827/ffffff?text=KicksVault+-+Elevate+Your+Step)

**KicksVault** adalah platform web e-commerce bertema sepatu yang dirancang modern, responsif, dan intuitif. Website ini hadir dengan 4 menu utama yang terstruktur untuk memberikan pengalaman belanja dan eksplorasi koleksi sepatu terbaik bagi penggunanya.

---

## 🌟 Fitur & Menu Utama

Website KicksVault terdiri dari 4 navigasi utama:

1. **🏠 Home (Beranda)**
   - *Hero Section* interaktif dengan penawaran/rilis terbaru.
   - Sorotan produk terlaris (*Bestseller*) dan kategori populer.
   - Nilai keunggulan toko (*Value Proposition*).

2. **🛍️ Shop (Katalog Produk)**
   - Display katalog sepatu lengkap (Sneakers, Running, Casual, Formal).
   - Fitur filter berdasarkan kategori, ukuran, dan rentang harga.
   - Kartu produk (*Product Card*) dengan harga, ulasan, dan tombol *Add to Cart*.

3. **ℹ️ About Us (Tentang Kami)**
   - Profil singkat dan visi-misi KicksVault.
   - Jaminan keaslian (*100% Original Authentic Kicks*).
   - Komitmen kualitas bahan dan layanan.

4. **📞 Contact Us (Kontak)**
   - Formulir pesan/pertanyaan pelanggan.
   - Informasi lokasi toko fisik/gudang dan peta interaktif.
   - Tautan media sosial dan layanan pelanggan (WhatsApp / Email).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman web semantik.
- **CSS3 / Tailwind CSS**: Penataan gaya visual yang bersih, responsif, dan modern.
- **JavaScript (ES6+)**: Interaktivitas menu, filter katalog, dan simulasi keranjang belanja.
